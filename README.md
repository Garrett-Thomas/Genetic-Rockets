## Genetic Rockets Simulation ##
A simple genetic rockets simulation that will show rockets learning a path to reach a target. The best rockets from each generation are selected to breed the next generation.

### Compilation
* Make sure you have emscripten and node installed.
* Run `npm run compileWASM`
* Navigate to the web folder and serve the files (Here is an easy way to do that: `python -m http.server`)
